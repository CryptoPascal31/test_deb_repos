Add this repository

Run these three commands on Debian or Ubuntu

1. Add the GPG key

curl -fsSL https://DOMAIN/public.gpg | sudo gpg --dearmor -o /usr/share/keyrings/kda-community-apt.gpg

2. Add the repository

echo "deb [signed-by=/usr/share/keyrings/kda-community-apt.gpg] https://DOMAIN/repo $(. /etc/os-release && echo $VERSION_CODENAME) main" | sudo tee /etc/apt/sources.list.d/kda-community.list

3. Update package lists

sudo apt update
